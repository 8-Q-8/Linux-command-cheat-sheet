					Linux Commands
 
"Note:- To use these commands the operator needs to open their terminal which can be accessed by Ctrl+Alt+T or through the Menu using the super key."
"Note:- Any Command using sudo would require a password."



    1 To check for updates and upgrade your applications 
        ◦ sudo apt update
Checks updates for application but does not install them.

        ◦ sudo apt upgrade
Downloads and installs the latest versions of all software packages currently installed on your system
To do them both in one go type

        ◦ sudo apt upgrade && upgrade
This command will check for updates and then install any new updates that are available

    2 Changing Directories in Linux
this command helps in navigating system directories and subdirectories
      
        ◦ cd [directory_name] example cd Download
         
     The directory names are case sensitive
          
          To move into a subdirector
      
        ◦ cd Document/cafe/receipts

    3 To remove a file from a directory
        ◦ rm [file name]

    4 To Check for active users
        ◦ id 

    5 To Check for last system logins
        ◦ last
